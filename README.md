# DEmuFM — Official Arcade Website

[**Visit the official DEmuFM website**](https://azrael11.github.io/DEmuFM-Home/)

DEmuFM is a Delphi / FireMonkey arcade emulator with a curated game library, configurable controls, full-screen screenshots, performance overlays and game information.

## Version 0.0.6 — Latest release

- **400 arcade games individually tested:** all are **playable** and run at their correct game-specific frame rates.
- **F11:** full-screen PNG screenshot capture with bezel and saved-path confirmation.
- **F12:** FPS / detailed performance overlay / off; Shift+F12 preserves the debugger.
- **Input:** corrected Thunder & Lightning mouse/keyboard responsiveness.
- **Video, audio and stability:** targeted driver improvements, sprite fixes and detailed SDL diagnostics.
- **Known issue:** intermittent SDL2 startup/shutdown access violation remains under investigation.

The experimental **1942 GR** OpenGL implementation is not part of the 400 supported games.

The original arcade gallery and game information remain available on the website. The v0.0.6 emulator release contains source code; no Windows executable is advertised as downloadable.
